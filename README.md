# Roblox Systems 🐝

A collection of small systems and game assets I'm building in **Roblox Studio using Luau** while learning game development.

## Projects

### 1. Basic Speed Management with Buttons
A simple speed management system that allows players to increase and decrease their movement speed using buttons.

**Status:** Basic implementation completed.

### 2. Collect – Store – Deposit
A system focused on collecting resources, storing them, and depositing them through gameplay mechanics.

**Status:** 🚧 In Progress — still under development.

### 3. Spinning Mystery Box
A custom Roblox-style lucky box model built in Roblox Studio, featuring a studded texture and a base. The model has a floating appearance and is designed for use as a collectible or reward in a Roblox experience.

**Status:** Model created; gameplay integration and additional functionality can be developed further.

## About

I'm learning Roblox development by building small systems, experimenting with Luau, and creating 3D assets.

This repository documents my progress as I work toward building complete Roblox experiences. Projects may be unfinished, experimental, or updated as I learn new skills.

More systems and assets will be added as development continues.
