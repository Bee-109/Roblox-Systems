# 🎁 Lucky Box

A Roblox-style lucky box model built in Roblox Studio, featuring a studded texture and mounted on a base. The model has a floating appearance, making it suitable for use as a collectible, reward, or interactive object in a Roblox experience.

## Features

- 🎁 **Lucky Box Design** — A simple, recognizable lucky box.
- 🧱 **Studded Texture** — Uses Roblox-style studs for a classic blocky appearance.
- 🪨 **Base Included** — The box sits on a dedicated base.
- ✨ **Floating Appearance** — Designed to look like it's hovering above its base.
- 🎮 **Game-Ready Model** — Built for easy integration into Roblox projects, with scripting and gameplay integration still possible.

## File Information

- **Format:** `.rbxm`
- **Created With:** Roblox Studio
- **Model Type:** 3D game asset

## Usage

1. Download `LuckyBox.rbxm`.
2. Open Roblox Studio.
3. Right-click `Workspace` in Explorer and select **Insert from File**.
4. Select the downloaded file to add the model to your experience.
